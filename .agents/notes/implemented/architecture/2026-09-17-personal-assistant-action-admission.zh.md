# Agent Note: 个人助理操作准入

Status: implemented

[English](2026-09-17-personal-assistant-action-admission.md) | 中文

## 问题

个人助理读取不可信的日历内容，并跨对话保留上下文。仅靠指令无法阻止这些内容请求无关工具或绕过写入审批。小型插件部署还需要持久化操作归属，而不重复实现 DSH 的权限或 Session 机制。

## 决策

独立的 `work-assistant` 工作区使用固定版本的已发布 DSH 包。其[网关 bundle](../../../../work-assistant/packages/wa-gateway/README.zh.md)负责连接器准入，无需修改 agent loop。部署必须使用独立的个人 DSH home，并排除通用执行、文件系统、浏览器及任意网络工具。

连接器注册确切的工具定义和固定的操作分类。网关通过[单调工具守卫](../feature/2026-06-30-interception-extension-points.zh.md)，比较调用 agent 可见的定义与自己持有的包装定义。名称匹配并不足够，因为 agent 作用域中的同名工具可以覆盖全局注册。

读取允许执行；每次写入都必须从现有的[单次审批服务](../feature/2026-07-06-approval-seam.zh.md)获得新授权。部署配置提供所有者身份，DSH 执行上下文提供 Session 和调用身份。模型参数不能替换这些身份或选择策略。外部内容接触标记仅是审计元数据，不能免除审批。

[限定作用域的人类提问贡献](../feature/2026-09-18-personal-assistant-receipts-and-questions.zh.md)独立于连接器分发，准入精确的内置交互定义。其答案仍是普通 Session 工具结果，不是写入授权，也不是重复的连接器审计正文。待定写入审阅使用捕获的参数，并会因同一实时 Agent 中的新直接人类输入而失效。

网关在执行前将准入记录持久化到带版本的 DSH 存储域。记录包含归属、参数摘要、决策及执行结果；Session 日志保存模型可见的参数和结果正文。重启时标记中断记录，而不重放。执行后的失败不能证明副作用未发生。

受信任的连接器代码在使用时解析凭据引用。引用可以避免将配置的订阅源凭据放入模型参数，但无法隔离同一进程内其他插件对凭据的访问。插件、配置及操作系统账户仍受信任。

[记忆 bundle](../../../../work-assistant/packages/wa-memory/README.zh.md)将每次经审批和版本核对的笔记替换与该笔记的本地提交绑定。可变记忆以工具结果数据而非系统指令的形式进入模型。Session 生命周期不是写入事务：一个 Session 可以跨越多轮对话和多次进程启动。

需主动启用的[简报 bundle](../../../../work-assistant/packages/wa-briefing/README.zh.md)使用受维护的 cron 定时器创建只读 DSH Agent。DSH Session 保存其提示词及结果。定时器仅存在于进程内，错过的发生时刻会被跳过。[主动收件箱决策](../feature/2026-09-21-personal-assistant-proactive-inbox.zh.md)负责持久暂停、发生时刻去重和回复送达。

## 考虑过的替代方案

**连接器可以绕过的辅助函数。** 模型可见工具可以完全不调用该函数。对确切注册定义进行准入检查，使连接器注册成为执行策略的一部分，而不只是命名约定。

**支持 Session 级或永久授权的第二套审批数据库。** 持久授权需要独立设计作用范围、撤销和过期语义。DSH 单次审批已满足本部署需求，无需新增权限系统。

**在操作审计中保存完整参数和结果。** DSH 已在 Session 中记录模型可见正文。重复保存会增加敏感数据副本，并引入另一套保留策略；操作审计仅保存元数据。

**将凭据间接引用当作插件沙箱。** 受信任的进程内代码可以访问相同的服务和环境。仍然需要进程／容器隔离及受限的 profile 组合；引用无法提供这种隔离。

**在 Session 结束时统一提交 Git。** 大范围提交可能包含无关编辑，而关闭进程不能可靠说明用户授权了哪篇笔记。逐次提交经审批的笔记，可将写入及其历史归属到同一个操作。

**依赖本地 Taskboard 源码。** 本工作区使用的已发布 DSH 版本不包含 Taskboard。依赖本地实现会将部署绑定到未发布的核心改动。小型 cron 消费方使用公开 Agent API，无需增加第二套持久任务数据库。

## 结果与影响

每个连接器工具都必须通过网关注册；限定作用域的提问工具需要精确交互准入。任意编码工具和企业 MCP 连接器不会自动可用；无人值守写入在没有审批答复方时拒绝执行。

[网关测试](../../../../work-assistant/packages/wa-gateway/tests/gateway.spec.ts)使用真实的注册表、审批服务和 SQLite 存储域，覆盖作用域内同名覆盖、调用归属、取消、存储失败、重启持久化及独立审计快照。这些证据不能证明真实账户或容器已可运行。

现有的作用域、拦截及审批决策仍是 DSH 本身的权威记录。助理新增的是部署策略，而不是替换这些机制，也不承诺跨 DSH 预览版本兼容。
