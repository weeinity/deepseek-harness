# Agent Note: 个人助理选择性表情回应

Status: implemented

[English](2026-09-19-personal-assistant-selective-reactions.md) | 中文

## 问题

对每条已准入消息自动竖拇指，描述的是送达，而不是对话回复。它可能在普通问候或实质回答旁产生多余标记。个人助理需要选择何时简单确认就已足够，何时需要文字或实际工作。

## 决策

[个人助理预设](../../../../work-assistant/packages/wa-preset/README.zh.md)允许对无需回答或行动的感谢、确认或低风险近况，偶尔仅用竖拇指回复。它不强制频率，也不在浏览器中对消息分类。问候、问题、实质请求、不明确的消息、困扰、错误和确认决定需要文字或实际工作。

[助理 UI](../../../../work-assistant/packages/wa-ui/README.zh.md#acknowledgement-reactions)将符合条件且已提交的纯表情回复显示为对应 Web 用户消息上的标记，而不在助理气泡中重复显示。普通回复和混合回复保留为普通消息。流式、失败和已取消的输出不能建立表情回应。普通助理消息仍是持久化和模型可见记录；轨迹和模型历史保留它。

配置的预设和展示策略限定此展示的作用域。关闭时保留普通表情回复，包括历史回复。表情回应既不是授权，也不能证明工作已完成。[回执与问题决策](2026-09-18-personal-assistant-receipts-and-questions.zh.md)中的共享用户标记槽位、输入来源、作用域问题和写入审批规则仍然有效；本决策仅取代自动准入回执策略。

## 考虑过的替代方案

**对每条已准入消息显示回执。** 准入是有用的传输事实，但不表达助理选择确认而非回答。把它显示为对话表情回应会误述这一选择。

**浏览器关键词规则、随机回应或固定频率。** 这些方法独立于模型制造回复，可能对实质或敏感消息作出不恰当回应。选择由助理已记录的回复拥有。

**专用确认工具和自定义持久事件。** 独立的助理回复已经记录该选择。工具增加执行和后续请求机制，却没有必要的副作用。

**替换原有渲染器或修改其 DOM。** 助理只拥有自身的表情回应展示。附件、普通文字、复制控件和其他对话展示仍由共享 Chat 负责。

## 后果

模型决定何时确认，所以提示词指导不保证特定回应频率。附着展示仅识别受支持的独立竖拇指；其他表情和混合回复仍显示为普通回复。UI 不增加独立模型调用、审批状态或确认事件。

聚焦测试覆盖无表情回应的普通回复、相同用户文字对应不同模型回复、精确消息身份、未完成和已取消输出、预设隔离、关闭展示及重放。已安装 profile 的浏览器覆盖还检查附着位置、复制文字和没有重复表情回复。这些 fixture 证明展示行为，不证明模型普遍遵循指导。
