# @deepseek-ai/dsh-client-ui-taskboard

[English](README.md) | 中文

## 概述

在五个工作流列中组织工作区任务，并通过 DSH 或 Copilot 运行已保存的提示词。每个任务保留一个当前会话、持久执行历史、可选定时任务和经过审核的交接上下文。再次运行会继续同一会话，直到你明确断开连接。优先级、标签、归档和可编辑副本支持执行过程中的任务规划。

<a id="use-this-package"></a>
## 使用本包

在包含[任务看板控制器](../../api/taskboard-controller/README.zh.md)的 Web 组合中，从侧栏打开**任务看板**。**新建任务**打开包含标题、描述、工作区、优先级、标签、独立运行提示词、执行设置和可选现有连接的未保存草稿。**保存并关闭**将任务保存到**待办**并关闭对话框；**保存**将任务保存后继续编辑。两者都不会启动工作。**取消**丢弃创建草稿，不改变看板。点击卡片打开详情。

运行获准后，任务移至“进行中”。成功后移至“已完成”；失败、取消或等待用户输入时移至“审核中”。恢复执行后回到“进行中”。

将卡片拖到其他列的标题、空白区域或卡片上，即可更改其已保存的状态，而不运行任务。拖动过程中，目标列会高亮显示。**全部工作区**和搜索筛选视图也支持状态变更；同列排序与按卡片定位仅适用于未筛选的单一工作区。在该视图中，放到最后一张卡片下方会将任务追加到列末尾。

放下的卡片保持已提交的位置，直到收到宿主更新。保存完成后才能再次拖动。保存失败会显示错误并保留已提交的任务。键盘用户可以打开卡片并使用状态控件；请先保存草稿修改。

列标题圆点和任务状态徽标使用统一配色：“积压”为灰色，“待办”为靛蓝色，“进行中”为蓝色，“审核中”为琥珀色，“已完成”为绿色。浅色、深色主题和归档卡片均使用同一调色板。

不使用“运行”而直接继续关联的 DSH Chat 时，其中的问题也会使任务移至“审核中”。使用**打开会话**即可回答。[宿主监控](../../api/taskboard-controller/README.zh.md#execution-and-connections)跟踪恢复与完成，不增加执行历史，也不关联无关 Chat。

**归档**和**删除**仅显示在已保存任务中，不显示在创建草稿中。**归档**将任务移到可筛选的归档列表。归档任务只读；**恢复**将任务移回看板，并保持定时运行关闭。**删除**需要确认，且只移除任务记录，不删除其会话。

保存草稿使用开始编辑时记录的修订号。新到达的修改不能默许旧草稿覆盖当前内容；修订冲突后，请重新打开任务，或通过**编辑为副本**保留自己的修改。

命令尚未完成时，不能关闭创建或详情对话框。**保存并关闭**位于**保存**之前，仅在保存成功后关闭。命令失败后，草稿和错误提示会保留，供用户重试。

**复制任务**在原任务所在列打开新任务草稿，不含连接、执行历史或权限确认。可通过**编辑为副本**将未保存的修改转为副本。可选的原任务归档是单独等待完成的操作：若失败，已创建的副本仍然保留，对话框允许重试而不会再次创建副本。

任务看板根据已保存的[宿主设置](../../api/taskboard-controller/README.zh.md)决定可用性、代理公告和空闲休眠保护。看板不提供设置对话框，也不会重置这些偏好。创建任务需要等待宿主运行时快照；运行时错误仍显示在看板上。

看板视觉以 Dashi Taskboard 为产品参考，不 vendoring 其源代码。Dashi Taskboard 使用 Apache-2.0 许可证：<https://github.com/chuspeeism/dashi-taskboard>。

## 运行任务

选择 DSH 或 Copilot，保存执行输入，然后选择**运行**。运行提示词留空时使用以空行分隔的标题和非空白描述；明确填写的提示词覆盖两者。执行结束后仍可**再次运行**，并继续同一已连接会话，直到**断开连接**。未保存的输入、未解决的连接选择或尚未结束的执行会阻止另一次运行。

宿主拥有接纳与派发操作。DSH 派发确认成功后打开 Chat，不等待模型执行完成；失败时详情对话框保持可见。详情按从新到旧显示等待派发、执行中、成功、失败与已取消的执行，包括时间戳、保存的输入、错误和各自的会话链接。不能打开等待派发的会话预留标识。已连接的 DSH Session 缺失时会明确报错，而不是替换它。

<a id="associate-an-existing-copilot-cli-session"></a>
## 连接现有会话

未连接的任务显示一个提供方选择器。DSH 选项来自所选工作区；Copilot 发现列出匹配的本地会话，并报告不可用或未完成的扫描。**连接**关联所选会话但不运行。当前连接只读；替换前必须**断开连接**。保留两个旧关联的任务需要明确选择其中一个。

**打开会话**导航到 DSH Chat。**打开/恢复 Copilot**请求现有 Agency 终端交接。两种操作都不发送任务提示词，也不重新创建缺失的会话；失败会持续显示。断开连接、重新连接或归档后，历史链接仍指向各自的会话。Copilot 已运行时会明确显示未打开额外终端，包括无界面执行的情况。只有客户端与宿主允许本地启动时，Copilot 终端导航才可用；运行可用性来自宿主执行目录。

具有当前任务关联的 DSH Session 会在顶部显示带白色复选框图标的紧凑蓝色圆角**打开任务**按钮，高度与相邻的会话控件一致。选择此按钮即可返回任务看板并打开任务详情。看板会清空搜索，并选择任务所属的工作区及活动或归档视图。如果多个任务关联同一 Session，可按任务编号和标题从菜单中选择。归档详情仍为只读；若任务在导航前被删除，会显示错误。打开任务不会运行任务。

<a id="start-a-task-with-agency-copilot"></a>
## 执行选项与定时任务

看板加载宿主的预设、权限和模型目录。损坏的预设仍然可见，但不可选择。Copilot 接受明确的模型 ID，而非虚构的目录选项。已连接任务和未解决的旧连接选择锁定工作区、提供方与预设选择。尚未结束的执行锁定执行输入编辑。仍可编辑标题、描述、标签和优先级；允许的状态变更不会改变冻结的执行。

定时任务提供五字段 cron 表达式、时区、启用开关，以及每天九点、每小时、每十分钟和周一九点预设。宿主验证表达式，并提供下次运行与上次触发时间。无效输入保留在草稿中，并显示服务端错误。

冻结的交接上下文包含目标、进展、下一步、引用、来源会话和冻结时间。无关修改会保留这些内容。扩大权限运行前，请审核已保存的权限和交接内容，选中明确的审核复选框，然后确认。新的任务修订会使尚未提交的审核失效。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现内部细节 — 点击展开</summary>

本插件贡献带键的 `main` 任务看板面板、`sidebar.panellist` 启动项和 Session 顶部导航。各入口通过框架绑定的 hook 读取控制器保持标识稳定的 observable。Session 和 Workspace 数据使用标准框架 hook；对话框草稿与筛选条件保留在组件本地。顶部导航从任务的当前关联推导链接；共享的 root store 仅传递一次性的任务 id，不保存任务记录。

只有宿主 Run 命令提交工作。客户端回调将关联、终端导航与规划变更分开。宿主任务更新决定列位置；投影中的 `allowedManualStatuses` 决定手动状态控件。[控制器](../../api/taskboard-controller/README.zh.md)拥有 Remote 投影与修订顺序；[领域](../../workspace/taskboard/README.zh.md)拥有持久化与执行规则。

不发布运行时不变式伴生入口：本展示插件没有需要核对的独立事件流或持久状态。

</details>

<a id="model-experience"></a>
## 模型体验

### 任务执行请求

#### 模型看到什么

对于已保存的运行提示词，例如 `Run these instructions`，**运行**请求宿主派发该文本。[控制器](../../api/taskboard-controller/README.zh.md#model-experience)负责组装模型输入。查看、连接、断开连接、打开会话和修改规划状态都不提交模型输入。

#### Token 影响

看板渲染不增加 token。宿主派发的提示词与交接上下文消耗普通输入 token。

#### KV Cache 影响

查看任务看板不改变会话历史。再次运行针对同一会话；提供方拥有请求缓存。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- 键盘卡片排序、评论、附件、GitHub/Linear 同步和多人云协作延期处理。
- Copilot 终端导航是本地 Agency 交接，不是浏览器 transcript 查看器。
- 创建副本后归档原任务明确采用非原子操作；失败需要单独重试。
- 全看板焦点陷阱与侧栏入口焦点恢复仍属于后续无障碍工作。
