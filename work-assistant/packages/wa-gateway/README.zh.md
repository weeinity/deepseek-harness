# 个人操作网关

[English](README.md) | 中文

## 概述

仅开放显式注册的助理操作和 preset 准入的精确作用域用户问题工具。读取无需提示；每次写入都需要新的 DSH 单次审批。审批缺失、拒绝、取消、不可用或已过期时，均不得执行写入。

<a id="configuration"></a>
## 配置

此 bundle 插入 `wa-gateway`。必填的 `ownerId` 标识单用户部署，须由 1–80 个字母、数字、点、下划线或连字符组成，且以字母或数字开头。bundle 使用 `personal`；profile 补丁可替换它。

仅在独立的个人 profile 中挂载。单调守卫检查实际注册的工具定义，拒绝名称相似的工具、作用域内的同名覆盖及被其他执行前策略强制允许的工具。连接器或 preset 交互插件卸载时撤销其准入。profile 还必须排除通用 shell、文件系统、代码执行、浏览器及任意网络工具。

受信任的连接器插件注册工具定义与固定的读写策略。网关从 DSH 执行上下文派生 Session 和工具调用身份；模型参数不能选择其他所有者、Session、策略、凭据或污染标记。凭据在使用时通过 DSH 凭据服务解析，绝不应进入工具参数或响应。

preset 可以按身份为一个 agent 作用域准入已发布的 `ask_user_question` 定义。该交互不是连接器执行：DSH 的普通问题事件和工具事件会记录它，回答绝不会授予日历、记忆或其他写入权限。

<a id="audit-and-ownership"></a>
## 审计与归属

`workassist` 存储域使用配置的 DSH 存储后端。SQLite 由 DSH 提供，无需第二套数据库实现。存储域版本 1 为每次连接器调用记录所有者、Session、调用、连接器、方法、参数摘要、外部内容接触标记、决策和执行结果。DSH Session 日志保存参数正文、工具结果、审批请求／决策事件以及用户问题事件。

执行前先持久化准入记录。存储失败时不启动新操作。重启时标记被中断的记录，绝不重放。执行后的失败并不能证明副作用未发生；本包不会自动重试。卸载时取消并等待进行中的操作结束，再关闭存储域。

网关在审计、审批和执行前快照 JSON 参数，因此记录的摘要和实际执行的载荷对应同一份已审阅输入。从写入审计准入开始到执行启动前，同一 live agent 的新直接人工输入会取消该审批；转发上下文和其他 agent 不会取消。

外部内容接触标记保守地记录尝试读取外部内容的行为，并在重启后保留。它是审计元数据，不能替代审批：即使 Session 未接触外部内容，写入也始终需要审批。

<a id="model-experience"></a>
## 模型体验

拒绝调用、审批结果和用户问题失败通过普通 DSH 工具结果呈现。成功的连接器输出由注册该工具的连接器负责。成功的用户问题输出由已发布的 ask-user 工具负责。此 bundle 不向模型上下文注入审计载荷或秘密。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 仅支持单用户部署和单次审批；不提供 Session 级或永久授权。
- 插件和配置是受信任的代码。进程内的凭据引用不能隔离恶意插件。
- 交互准入仅限 `ask_user_question`；它是用于人工输入的守卫准入，不是连接器策略路径。
- 审计结果描述连接器执行，而非之后的工具结果呈现或用户接收情况。
- 不提供运行时 invariant companion：DSH 存储域负责记录校验，工具注册表负责准入 effect。
